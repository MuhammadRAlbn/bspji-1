# Aktivasi

Deploy perubahan source menggunakan prosedur proyek; perbarui cache/opcache atau proses yang berjalan lama bila deployment biasanya memerlukannya. Tidak ada migration atau perubahan `.env`.

FAP aktif membuka Zona Integritas > Riwayat Penghapusan, mencari nomor/judul/penghapus/alasan, membaca detail, dan mengunduh lampiran yang tersedia. Seluruh penghapusan dapat dilihat, termasuk yang dilakukan admin/FAP lain. Histori tetap hanya dapat dibaca. Waktu tetap ditampilkan sebagai WIB.

Admin dan Kepala Balai tetap memiliki akses baca. Humas, role tidak valid, akun nonaktif, dan tamu tidak mendapat akses. Penghapusan langsung melalui SQL tetap di luar pencatatan aplikasi.
